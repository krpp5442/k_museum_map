# 대한민국 박물관 지도 - 전체 웹사이트 기본 프로젝트

## 포함된 기능
- 대한민국 10개 지역의 실제 시도 경계 GeoJSON 지도
- 지역 선택 후 시군구 경계 지도 표시
- 서울은 시군 선택을 생략하고 박물관 목록으로 이동
- 시군구 지도 클릭 및 오른쪽 목록 선택
- 박물관 통합 검색 및 지역 내 검색
- 박물관 공식 홈페이지 새 탭 연결
- PC/모바일 반응형 화면
- 박물관 정보 확인일·지역·주소·설명 표시 필드
- 무료 정적 호스팅(GitHub Pages 등)에 배포할 수 있는 구조

## 실행
1. 압축 해제
2. VS Code에서 이 폴더 열기
3. Live Server 확장 프로그램 설치
4. index.html에서 우클릭 → Open with Live Server

인터넷 연결이 필요합니다. Leaflet, OpenStreetMap 지도 타일, GeoJSON 경계 자료를 외부에서 불러옵니다.

## 파일
- index.html: 화면 구조
- style.css: 디자인
- app.js: 지도·검색·화면 전환
- data/museums_with_metros.json: 박물관 데이터

## 박물관 정보 추가
data/museums_with_metros.json의 museums 배열 안에 아래 형식으로 추가합니다.

{
  "id": "기관 고유 ID",
  "name": "박물관 공식 명칭",
  "regionId": "jeonbuk",
  "regionName": "전북특별자치도",
  "sigunguCode": "시군구 GeoJSON의 SIG_CD 값",
  "cityName": "군산시",
  "address": "공식 주소",
  "website": "https://기관의-공식-홈페이지",
  "description": "간단한 소개",
  "updatedAt": "2026-11-14"
}

중요:
- website에는 실제 기관이 운영하는 공식 홈페이지 주소를 입력하세요.
- sigunguCode는 지도 경계 데이터의 SIG_CD 값과 정확히 일치해야 합니다.
- 서울 박물관은 regionId를 "seoul"로 입력하면 서울 목록에 표시됩니다. 서울은 sigunguCode가 필요하지 않습니다.
- 이 프로젝트에는 검증되지 않은 박물관 목록이나 가짜 홈페이지 주소를 넣지 않았습니다.

## 행정구역 경계 자료
현재 앱은 아래 공개 GeoJSON 자료를 CDN으로 불러옵니다.
- https://github.com/KnellBalm/kr-admin-geojson
- 시도: ctprvn.geojson
- 시군구: sig.geojson
- 데이터 설명에 기재된 원본은 국가공간정보포털(V-World) 행정구역 경계 자료이며, 2023-07-29 배포본을 재투영·단순화한 자료입니다.
- 배포 전에는 원본 라이선스와 출처 표시 조건을 다시 확인하고, 가능하면 GeoJSON 파일을 프로젝트 내부 data/maps 폴더에 저장해 외부 CDN 의존도를 낮추세요.

주의: 현재 시군구 경계 자료는 시군구 코드 단위 250개 피처를 포함합니다. 일부 시의 구(예: 수원시 장안구)도 별도 경계로 나타날 수 있습니다. 도 단위 아래 행정구역 경계 선택을 위한 표시이며, 법적·행정적 경계의 최신성을 보증하는 서비스는 아닙니다.

## 지도 비용과 운영
- Leaflet: 오픈소스 라이브러리
- OpenStreetMap: 지도 데이터 및 타일 이용 정책 준수 필요. 공식 타일 서버는 무제한 무료 서비스가 아니므로 트래픽이 커지면 별도 타일 제공 업체를 검토하세요.
- GitHub Pages 등 정적 호스팅을 이용하면 초기 서버 비용을 0원으로 시작할 수 있습니다.
- 사용자 계정, 즐겨찾기 동기화, 관리자 로그인 등 서버 기능을 추가하면 별도 백엔드/DB 비용이 생길 수 있습니다.

## e뮤지엄 API 관련
국립중앙박물관 e뮤지엄 Open API는 소장품 정보 중심의 API입니다. 박물관 디렉터리의 기관 홈페이지 주소를 자동으로 완성하는 API라고 단정할 수 없습니다. API 키 발급과 제공 필드 확인 후 별도 기능으로 연결해야 합니다.


## 박물관 데이터 반영 안내
- `data/museums_with_metros.json`에는 제공된 엑셀의 「지역별 목록」 시트 항목만 반영했습니다.
- 「추가 확인 필요」 시트는 이번 데이터에 포함하지 않았습니다.
- 홈페이지 주소가 URL이 아닌 메모 또는 공란인 기관도 목록에는 표시되며, 링크 대신 확인 필요 안내가 표시됩니다.
- 시·군·구 연결은 지역 ID와 시·군·구 명칭으로 처리합니다.
- 원본 엑셀의 주소를 옮겼으며 각 주소의 현재 접속 가능 여부는 별도 검증하지 않았습니다.


### 구 단위로 나뉘는 시의 박물관 표시
수원시·창원시·포항시처럼 행정구역 GeoJSON에서 시 내부가 일반구 단위로 나뉘어 표시되는 경우를 처리했습니다.
- 박물관 데이터의 `cityName`이 `수원시`처럼 시 단위이면, `수원시 장안구` 등 해당 시의 구를 선택해도 표시됩니다.
- `cityName`이 `수원시 장안구`처럼 구 단위로 입력되어 있으면 해당 구에서만 표시됩니다.
- 시 단위로만 등록된 기관은 해당 시의 각 구에서 중복 표시될 수 있습니다. 정확히 구별하려면 해당 기관의 `cityName`을 실제 소재 구까지 확인해 입력해야 합니다.


### 시·군 단위 표시
지도와 선택 목록은 시·군 단위로 표시합니다. 수원시·성남시·고양시·용인시·창원시·포항시 등 내부가 일반구로 나뉜 시는 구 경계를 하나의 시 영역으로 묶어 보여줍니다. 따라서 `장안구`, `성산구` 등의 구 이름은 선택 목록에 별도로 나타나지 않습니다. 박물관 데이터에 구 단위 명칭이 입력된 경우에도 상위 시 이름으로 정규화하여 해당 시 목록에 표시합니다.

### 시·군 목록의 행정구역 처리
- 전북특별자치도는 GeoJSON 자료에 남아 있을 수 있는 구 전라북도 코드(45)와 현행 코드(52)를 모두 인식합니다.
- 강원특별자치도와 제주특별자치도도 구 코드(42, 49)와 현행 코드(51, 50)를 함께 인식합니다.
- 도 선택 화면에서는 인접 광역시를 편의상 함께 표시합니다: 경상북도-대구광역시, 경상남도-부산광역시·울산광역시, 충청남도-대전광역시, 전라남도-광주광역시.
- 광역시 내부의 구 경계는 광역시 이름 하나로 합쳐 표시하며, 도 내부의 일반구도 상위 시 이름 하나로 합쳐 표시합니다.


## 이번 배포본 안내

압축을 풀면 `대한민국_박물관지도_광역시포함` 폴더가 생성됩니다. 박물관 데이터는 `data/museums_with_metros.json`을 사용하며, 기존 10개 지역 92곳과 6개 광역시 50곳을 통합한 총 142곳이 포함되어 있습니다. 광역시는 인접 도 선택 화면에 포함되도록 설정되어 있습니다.
